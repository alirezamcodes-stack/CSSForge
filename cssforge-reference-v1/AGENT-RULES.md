# CSSForge — Agent Rules

1. **Implementation first.** Do not spend a run re-researching the whole product.
2. Read only the current phase file plus the two core docs it names.
3. Open only the evidence assets listed by the current phase.
4. Do not inspect every video/contact sheet automatically.
5. Do not write large audit reports before implementation.
6. Every phase ends with:
   - implementation,
   - focused tests,
   - 2–5 screenshots,
   - short gap note.
7. If the screenshot is visibly wrong, refine it before adding more features.
8. CSS Pro governs visible hierarchy and interaction where evidence exists.
9. Use independent CSSForge code, branding, icons and wording.
10. Do not fake functionality in production.
11. Development fixture data is allowed only in the UI-foundation phases.
12. Keep engine/business logic outside React presentation components.
13. Do not start the next phase automatically.
