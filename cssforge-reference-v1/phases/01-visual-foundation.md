## Goal
Create the new CSSForge extension from zero using WXT + TypeScript + React.

Use fixture data. Do not build a CSS analysis engine.

Build:
- content-script Shadow Root app
- floating inspector shell
- selected-element header
- Design / Code / HTML tabs
- Media and State/Pseudo controls as visual fixtures
- compact geometry row
- Design sections
- spatial Spacing component
- Typography component
- Background/Display/Border/Position/Shadow/Filter visual structures
- Code visual surface
- HTML/Navigator visual surface
- bottom floating dock
- dedicated Changes visual surface
- shared menu/popover shell

Controls may be fixture-driven but must behave honestly in dev mode; do not imply production functionality.
