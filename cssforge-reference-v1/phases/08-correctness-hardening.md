# Phase 08 — Correctness + Hardening

This phase happens only after visual/interaction foundations are accepted.

## Build
- stylesheet indexing
- authored vs computed provenance
- specificity
- conservative cascade diagnostics
- root-aware selectors
- Shadow DOM boundaries
- inaccessible stylesheet handling
- performance budgets
- deterministic cleanup
- broader tests

Keep engine logic separate from UI.

Do not redesign the UI during this phase unless a correctness requirement genuinely needs presentation.
