# CSSForge Reference V1

Compact, phase-oriented reference package for a new WXT + TypeScript + React Chrome extension.

The package intentionally includes:
- a small number of core text documents,
- curated primary screenshots,
- 14 video contact sheets,
- only a few keyframes per video,
- no dense 1fps extraction,
- no raw MP4 files,
- phase files that tell the agent exactly what to read.

Start with `00-START-HERE.md`.
